# Overview

This project is a simple Hello World program written in JavaScript and executed using Node.js. The goal is to strengthen my foundation in software development by learning how to set up a runtime environment, write basic code, and run it successfully outside of the browser.

The purpose of this software is to demonstrate the ability to:
-Install and configure Node.js on a local machine.
-Write a minimal JavaScript program.
-Execute the program in a terminal environment.

# Development Environment

Tools Used:
Node.js
Visual Studio Code
Terminal (to run the program)

Programming Language:
JavaScript (ES6 syntax)
